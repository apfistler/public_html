# Adam Fistler — Website

This repository is a public backup of the website files used by **Adam Fistler Services**.

The site contains information and resources covering:

- Hypnosis
- Addiction & Recovery
- Mindfulness
- Behavior Change
- Astrology
- Handwriting Analysis
- Groups & Workshops
- Parties & Events
- Technology

## Purpose

This repository serves primarily as:

- A version-controlled backup of the website
- A historical record of website development
- A safe place to experiment with changes before deploying them
- A publicly accessible copy of the site's source files

The repository contains the site's HTML, CSS, JavaScript, images, SVG artwork, configuration, and other web assets.

## Site

**Adam Fistler Services**

https://www.adamfistler.com/

## Development

The website is built primarily with hand-written:

- HTML
- CSS
- JavaScript
- SVG
- YAML
- Python

The site does not depend on WordPress, Bootstrap, React, or other large web frameworks.

A custom Python static-site generator, **Cinnamon**, is used to generate portions of the site from source content, templates, configuration, and reusable snippets.
